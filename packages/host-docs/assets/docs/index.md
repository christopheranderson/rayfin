# Rayfin host services overview

Rayfin host services run the Data API Builder, authentication endpoints,
and storage abstractions inside .NET 8 process hosts. The host components
live under `packages/host/` in the project-rayfin monorepo and ship as
NuGet packages:

- **Microsoft.Rayfin.WebService** — ASP.NET Core web service host and
  HTTP entrypoint. Exposes the GraphQL endpoint generated from a
  Rayfin project's entity declarations.
- **Microsoft.Rayfin.WebService.Tests** — MSTest suite for the web
  service host, validating endpoints and infrastructure.
- **Microsoft.Rayfin.Common** — shared .NET utilities, configuration,
  and cross-cutting infrastructure for host services.
- **Microsoft.Rayfin.Auth** — authentication and authorization helpers
  for Rayfin hosts (NuGet).
- **Microsoft.Rayfin.Storage** — storage abstractions and Azure
  Storage integration.
- **Microsoft.Rayfin.DataApi** — Data API Builder integration.
- **Microsoft.Rayfin.Function** — function-style hosting primitives.

See the per-component pages:

- [WebService quickstart](./web-service.md)

## Architecture context

The host components consume the DAB configuration generated by the
TypeScript SDK + `rayfin-cli`. A Builder defines entities in TypeScript;
the CLI emits a DAB configuration; the WebService host loads it at
startup and exposes the GraphQL endpoint. Authentication, authorization,
and policy enforcement happen inside the host's middleware chain via
`Microsoft.Rayfin.Auth`.
