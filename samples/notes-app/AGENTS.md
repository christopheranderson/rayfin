# Notes App - Agent Context

Scope: Builders and agents working on the notes-app.
This file provides implementation context, commands, and workflows for AI assistants.

## Commands

Provision or reuse the Fabric backend and start local development:

```bash
npm run dev
```

## Environment

Source of truth: `rayfin/.env` (`RAYFIN_PUBLIC_*` prefix).
`rayfin dev` generates `.env.local` before starting the frontend.

Vite frontend variables (in `.env.local`):

- `VITE_RAYFIN_API_URL` – Rayfin backend URL (default `http://localhost:5168`); sourced from `RAYFIN_PUBLIC_API_URL`
- `VITE_RAYFIN_PUBLISHABLE_KEY` – Rayfin publishable key; sourced from `RAYFIN_PUBLIC_PUBLISHABLE_KEY`
- `VITE_FABRIC_ITEM_ID` – Rayfin item ID; sourced from `RAYFIN_PUBLIC_ITEM_ID` (written by `rayfin up`)

Config files:

- `.env` – defaults for all environments
- `.env.local` – generated by `rayfin env --framework vite` (git-ignored)
- `rayfin/.env` – runtime and deployment values (git-ignored)

## Architecture and Services

ServiceContainer provides Rayfin-backed services:

- `ServiceContainer.create()` → Rayfin services via Rayfin client

Key services:

- Auth: `RayfinAuthService` (uses `@microsoft/rayfin-client`)
- Notes: `RayfinNoteService` (GraphQL fluent API)
- Notebooks: `RayfinNotebookService` (GraphQL fluent API)

Custom hooks wrap services for React components:

- `useAuth()` – authentication state and operations
- `useNotes()` – note CRUD, filtering, pin toggling, and reload
- `useNotebooks()` – notebook CRUD, default notebook, and organization

## Components

- `LoginForm` – email/password login form
- `NoteEditor` – note creation and editing
- `NoteList` – displays list of notes
- `NoteViewer` – read-only note display
- `NotebookNav` – sidebar notebook navigation
- `icons/` – shared icon components

## Rayfin Integration Points

Decorators (`@microsoft/rayfin-core`):

- `rayfin/data/Note.ts` – note entity with decorators for DAB schema
- `rayfin/data/Notebook.ts` – notebook entity with relationships

Client (`@microsoft/rayfin-client`):

- `RayfinClientService` manages a singleton Rayfin client
- `getRayfinClient()` returns the initialized client for services

Data API (`@microsoft/rayfin-data`):

- `RayfinNoteService` uses the GraphQL fluent API (`rayfinClient.data.gql`)
- Queries and mutations are type-safe and DAB-compliant

## Generated and Do-Not-Edit Files

Do not edit these paths; treat them as build or local-state outputs:

- `rayfin/.temp/` – Rayfin/DAB config generation output
- `dist/` – Vite build output
- `.env.local` – local environment overrides (git-ignored)

## Workflows

Full-stack development:

1. Run `npm run dev`.
2. Open the printed URL and sign in or register.
3. Deploy the complete app to Microsoft Fabric for production using `npx rayfin up`.

See `README.md` for detailed setup instructions.

## Rayfin data/auth guidance (MCP required)

When generating or editing **data-relation code**, **data-query code**, or **auth-related code**, use the **Project Rayfin MCP** (`mcp_Project-Rayfin_*`) for up-to-date docs and patterns. Call `mcp_Project-Rayfin_get_doc` or `mcp_Project-Rayfin_search_docs` before writing entity or query code.

This includes:

- Data modeling + relations: `@entity`, `@one`, `@many`, inverse relations
- Permissions/roles: `@role`, `@permissions`, `@authenticated`, `@anonymous`
- Data API/query code: select/filters/order/pagination
- Auth flows: sessions, sign-in/sign-up, auth SDK usage

Suggested doc entrypoints:

- `guide:docs/guide/data/overview.md`
- `guide:docs/guide/auth/overview.md`
- `ts-sdk:docs/ts-sdk/@microsoft/rayfin-data/index.md`
- `ts-sdk:docs/ts-sdk/@microsoft/rayfin-auth/index.md`
